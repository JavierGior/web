BI Dashboard D3.js DC.js Crossfilter.js freelance

Interactive BI dashboard developed for HSBC's Transformation area. The goal was to solve the team's data management challenge by creating a tool that merges data from 4 different teams, enabling both data exploration and executive presentations in a unified interface.

The solution delivers a cohesive aesthetic and cross-device performance, built as a web/mobile app in pure JavaScript with no server-side frameworks. Data is anonymized in the demo version.
